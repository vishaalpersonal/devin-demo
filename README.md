# devin-demo — AcmePay Ops Console

Build-vs-buy prototype: a lightweight in-house alternative to Retool for a
fintech's three internal apps (KYC review, refunds, feature flags), built as a
~2-hour proof of concept with Devin.

- `my-app/` — the Next.js application (setup + docs in its README)
- `ARCHITECTURE.md` — one-page architecture overview and tradeoffs
- `infra/` — mocked Pulumi deployment sketches (AWS/Azure/GCP), never deployed
